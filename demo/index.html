04 / Race systems

A race, not a moving diagram.

Deterministic systems own the sporting state. UI surfaces display it; hosts can configure and control it without reimplementing race logic.

See the active race configuration 
rules: {
  ruleset: 'grandPrix2025',
  modules: {
    pitStops: { enabled: true },
    tireStrategy: { enabled: true, mandatoryDistinctDryCompounds: 2 },
    tireDegradation: { enabled: true },
    stalledDnf: { enabled: true },

05 / Advanced physics

Explore advanced physics.

A separate, opt-in lab for advanced vehicle dynamics and the controls a model receives. The automatic races elsewhere use arcade physics.

Loads only when requested

Experimental driving + sensor lab

Experimental Formula-style handling: tires share grip between braking, acceleration and turning. Click the race to focus it, drive with the arrow keys or WASD, and press P to request a pit stop. Tap left/right for small corrections and hold for tighter turns. Keyboard traction assistance eases the accelerator when tires run out of grip.

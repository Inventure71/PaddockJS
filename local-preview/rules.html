Rule Modules

Rules a host can decide

A compact reference for the host-facing `rules` object: presets, start behavior, pit modules, tire modules, stalled DNF, penalties, and reserved future systems.

Coverage

Configurable race rules listed on this page

These are package options that host apps can pass to `mountF1Simulator()` or `createPaddockSimulator()`.

Race base

Preset and start controls

The top-level rules choose the base preset and whether the field waits behind start lights.

ruleset Default: paddock

Chooses the starting rule preset before explicit module overrides are merged.

Supported
`paddock`, `grandPrix2025`, `fia2025`, `custom`.
Override behavior
Explicit `rules.modules` values win over preset defaults.
rules: {
  ruleset: 'fia2025',
}
standingStart Default: on

Controls whether cars wait for the start-light sequence or immediately run under green.

`true`
Grid slots are locked until lights out.
`false`
Useful for training loops and rolling-start style demos.
rules: {
  standingStart: false,
}

Active modules

Systems with current simulator behavior

Each module lives under `rules.modules` and can be tuned independently.

pitStops Default: off

Enables automatic pit entry, team queueing, service, tire changes, and exit routing.

Speed
`pitLaneSpeedLimitKph` sets the main pit-lane limiter.
Flow
`maxConcurrentPitLaneCars`, `minimumPitLaneGapMeters`, and `doubleStacking` tune routing pressure.
Service
`defaultStopSeconds` and `variability` control stop duration.
rules: {
  modules: {
    pitStops: {
      enabled: true,
      pitLaneSpeedLimitKph: 80,
      defaultStopSeconds: 2.8,
    },
  },
}
tireStrategy Default: off

Controls available tire compounds, tire-choice pit service, and mandatory compound rules.

Compounds
`compounds` lists legal tire codes, usually `S`, `M`, and `H`.
Requirement
`mandatoryDistinctDryCompounds` sets the race classification requirement.
rules: {
  modules: {
    tireStrategy: {
      enabled: true,
      compounds: ['S', 'M', 'H'],
      mandatoryDistinctDryCompounds: 2,
    },
  },
}
tireDegradation Default: on

Lets tire energy wear down from driving load and affect grip through the physics model.

`true`
Energy decreases with throttle, brake, and lateral load.
`false`
Freezes tire energy for deterministic training or visual comparisons.
rules: {
  modules: {
    tireDegradation: { enabled: false },
  },
}
stalledDnf Default: off

Retires cars that are off legal racing or pit surfaces and nearly stationary for too long.

Timer
`maxStoppedSeconds` controls how long the car may stay stuck.
Speed
`speedThresholdKph` sets the stationary threshold.
Exclusions
Pre-start, red flag, legal pit surfaces, active pit handling, and already-finished cars do not count.
rules: {
  modules: {
    stalledDnf: {
      enabled: true,
      maxStoppedSeconds: 12,
      speedThresholdKph: 5,
    },
  },
}
penalties Default: off

Enables stewarded consequences for track limits, collisions, tire requirements, and pit-lane speeding.

Strictness
Penalty subsections use `strictness` from `0` to `1`.
Consequences
Supported outcomes include warnings, time penalties, drive-through, stop-go, position drops, grid drops, and disqualification.
UI
`ui.penaltyBanners` and `ui.timingPenaltyBadges` make penalties visible in browser mounts.
rules: {
  modules: {
    penalties: {
      enabled: true,
      trackLimits: { strictness: 0.8 },
      collision: { strictness: 0.5, consequences: [{ type: 'time', seconds: 5 }] },
      tireRequirement: { strictness: 1, consequences: [{ type: 'time', seconds: 10 }] },
      pitLaneSpeeding: { strictness: 1, speedLimitKph: 80 },
    },
  },
}

Reserved keys

Future modules that normalize but do not affect pace yet

These keys are part of the module vocabulary so hosts can keep stable config shapes while the simulator evolves.

weather Reserved future module

Normalized today, but it does not change grip, visibility, strategy, or car pace.

rules: {
  modules: {
    weather: { enabled: false },
  },
}
reliability Reserved future module

Normalized today, but it does not create random failures or mechanical retirements.

rules: {
  modules: {
    reliability: { enabled: false },
  },
}
fuelLoad Reserved future module

Normalized today, but it does not change car mass, power delivery, or stint pace.

rules: {
  modules: {
    fuelLoad: { enabled: false },
  },
}
